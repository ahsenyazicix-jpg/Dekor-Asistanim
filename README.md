# 3 Boyutlu Mekan Tasarım ve Mobilya Fiyatlandırma Platformu

# 

# \## Proje Hakkında

# Kullanıcıların odalarını 3 boyutlu tasarlayabildiği, mobilya ekleyip yerleştirebildiği ve anlık fiyat hesabı yapabildiği bir web uygulamasıdır.

# 

# \## Özellikler

# \- Kullanıcı kayıt ve giriş sistemi

# \- 3D oda oluşturma

# \- Mobilya sürükle bırak ve taşıma

# \- Anlık fiyat hesaplama

# \- Tasarım kaydetme

# 

# \## Teknolojiler

# \- Frontend: HTML, CSS, JavaScript, Three.js

# \- Backend: Node.js, Express.js

# \- Veritabanı: MySQL
